XCutors is a collection of popular Roblox executors bundled with a universal loader for convenient script management on Windows.

### Which executors are included?

The collection includes Volt, Synapse Z, Potassium, Wave, and the xcutorsLoader universal loader.

### Is XCutors free?

XCutors itself is free to use. Individual executor licenses may vary.

### What Windows versions are supported?

XCutors supports Windows 10 and Windows 11 (64-bit).

### How do I update an executor?

### Can I add my own scripts?

Yes, the script library lets you add, organize, and favorite your own Lua scripts.

### Where do I report bugs?
